Animations Reference

Setup requirements:
  • Import: Enable the browser animation capabilities by importing provideAnimations() in app.config.ts.
  • Trigger: Decorate components with the animations array.
  • Template Binding: Bind triggers using @triggerName or [@triggerName]="state" syntax.

State & Transition Config

Defining card states and transition curves.

import { trigger, state, style, animate, transition } from '@angular/animations';

@Component({
  animations: [
    trigger('openClose', [
      state('open', style({
        height: '140px',
        opacity: 1
      })),
      state('closed', style({
        height: '60px',
        opacity: 0.7
      })),
      transition('open <=> closed', [
        animate('0.3s cubic-bezier(0.4, 0, 0.2, 1)')
      ])
    ])
  ]
})

Stagger & Querying

Delaying sequential element transitions dynamically.

trigger('listAnimation', [
  transition('* => *', [
    query(':enter', [
      style({ opacity: 0, transform: 'translateX(-30px)' }),
      stagger('80ms', [
        animate('0.25s ease-out', style({ opacity: 1, transform: 'translateX(0)' }))
      ])
    ], { optional: true })
  ])
])
