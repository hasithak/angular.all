Modern Control Flow

Explore Angular's built-in control flow (@if, @for, @switch) introduced in v17, offering better type checking, no module import overhead, and up to 90% faster runtime checks.

check_circle_outline

1. Conditional Blocks (@if / @else)

@if / @else allows rendering HTML fragments based on logic. Unlike *ngIf, it requires zero module imports and provides direct typescript narrowings.
@if (isPanelVisible()) {
visibility Active State: The condition is true. Rendering primary content block.
} @else {
visibility_off Fallback State: The condition is false. Rendering else content block.
}
list

2. Loop Operations (@for with @empty)

@for renders list items. It requires a mandatory track expression for performance tracking. The @empty block renders automatically when the list contains zero entries.
@for (task of tasks(); track task.id; let index = $index; let total = $count) {
#{{ index + 1 }} of {{ total }}: {{ task.title }}
{{ task.status }}
} @empty {

No tasks left. The @empty block is now actively rendered.
}

3. Multi-path Switch (@switch)

@switch matches expressions and renders corresponding cases. It operates like native javascript switch statements.
Neon Pink Cyber Blue Emerald Glow
@switch (currentTheme()) { @case ('neon-pink') {
lens Neon Pink Theme Block Active
} @case ('cyber-blue') {
flash_on Cyber Blue Theme Block Active
} @case ('emerald-glow') {
eco Emerald Glow Theme Block Active
} @default {
Default Theme Block Active
} }

Control Flow Reference

Why use built-in control flow?
  • Import Less Code: No need to import CommonModule or NgIf / NgFor into standalone components.
  • Type Safety: Better type-narrowing inside conditional blocks (e.g. strict null checks).
  • Performance: Native compiler translation leads to micro-optimizations that perform faster than directives.

@if / @else syntax

@if (isPanelVisible()) {
  <div class="visible-panel">Visible Content</div>
} @else {
  <div class="hidden-panel">Else Fallback Content</div>
}

@for / @empty syntax

<!-- "track" is mandatory -->
@for (task of tasks(); track task.id; let idx = $index) {
  <div class="task-item">
    {{ idx + 1 }}. {{ task.title }}
  </div>
} @empty {
  <!-- Renders automatically when tasks list is empty -->
  <div class="empty-state">No tasks left.</div>
}

@switch syntax

@switch (currentTheme()) {
  @case ('neon-pink') {
    <div class="neon-pink">Pink Mode</div>
  }
  @case ('cyber-blue') {
    <div class="cyber-blue">Blue Mode</div>
  }
  @default {
    <div>Standard Mode</div>
  }
}
