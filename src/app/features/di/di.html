Code Sample & Concept Explanation

Hierarchical Injector System & Modifiers:
  • value providers (useValue): Bind static values or structures to DI tokens. Ideal for endpoints, keys, and global environments.
  • factory providers (useFactory): Calculate resolved values at runtime, utilizing other injected services as inputs.
  • class providers (useClass): Substitute implementations (e.g. replacing standard ErrorHandler with GlobalErrorHandler).
  • Resolution Modifiers: Define where lookups start (e.g., @SkipSelf() starts at parent) and when to fail gracefully (@Optional()).

1. Value & Factory Providers

Reading values in HTML templates, followed by configuration setups in app.config.ts.

<!-- HTML Template Usage -->
<div>Resolved API: {{ apiUrl }}</div>
<div>Prefix: {{ loggerConfig.prefix }}</div>

<!-- Provider Registration in app.config.ts -->
// 1. Value Provider registration
{ provide: API_URL, useValue: 'https://api.example.com' },

// 2. Factory function and registration
export function loggerConfigFactory(config: AppConfig): LoggerConfig {
  return {
    prefix: `[${config.appName}]`,
    logLevel: config.environment === 'production' ? 'warn' : 'debug'
  };
}

{
  provide: LOGGER_CONFIG,
  useFactory: loggerConfigFactory,
  deps: [APP_CONFIG]
}

2. Resolution Modifiers Usage

Configuring injector tree search scopes using constructor decorator tokens.

import { Component, Self, SkipSelf, Optional } from '@angular/core';

@Component({
  selector: 'app-di-grandchild',
  template: `
    <li>Self: {{ selfVal }}</li>
    <li>SkipSelf: {{ skipSelfVal }}</li>
  `
})
export class DiGrandchildComponent {
  constructor(
    // Looks only at grandchild; resolves to null if missing instead of error
    @Self() @Optional() private selfSvc: ValueService,

    // Starts lookup at child injector, bypassing grandchild
    @SkipSelf() @Optional() private skipSelfSvc: ValueService
  ) {}
}
