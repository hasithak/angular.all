2. Programmatic Creation (ViewContainerRef)

ViewContainerRef.createComponent() instantiates a component class imperatively in TypeScript. This allows full access to the component reference for passing input signals, subscribing to outputs, or manual destroying.

Dynamic Component Reference

Dynamic loading use cases:
  • Dashboard Widgets: Render custom widgets depending on user roles or profile choices.
  • Modals & Dialogs: Mount dynamic component sheets directly on global container elements.
  • Dynamic Forms: Compile complex conditional questionnaires.

Declarative: ngComponentOutlet

Injecting and rendering a component type directly in HTML templates.

<!-- HTML View Template -->
<ng-container [ngComponentOutlet]="widgetType"></ng-container>

<!-- TypeScript Controller -->
import { InfoWidgetComponent } from './widgets';

public widgetType = null;

public loadInfoWidget() {
  this.widgetType = InfoWidgetComponent;
}

Programmatic: ViewContainerRef

Creating component instances imperatively to handle bindings and lifecycle events in code.

<!-- HTML Anchor Element -->
<div #programmaticContainer></div>

<!-- TypeScript Controller -->
import { ViewContainerRef, ViewChild, ComponentRef } from '@angular/core';
import { AlertWidgetComponent } from './widgets';

@ViewChild('programmaticContainer', { read: ViewContainerRef })
private container!: ViewContainerRef;

private compRef: ComponentRef<AlertWidgetComponent> | null = null;

public mountWidget() {
  this.container.clear(); // Destroy previous instances
  this.compRef = this.container.createComponent(AlertWidgetComponent);
  
  // Set component inputs directly
  this.compRef.instance.alertTitle = 'System Critical';
  
  // Clean up manually on destroy
  // this.compRef.destroy();
}
