Code Sample & Concept Explanation

Angular Forms Architectures:
  • Reactive Forms: Programmatic, structured, synchronous, and reactive. All validations and structures are managed inside TypeScript.
  • Template-Driven Forms: Direct template bindings (ngModel). Validation attributes (like required or email) are evaluated directly on DOM inputs.
  • Validators: Synchronous validators return validation error maps immediately. Asynchronous validators return Observables/Promises emitting verification status.

1. Reactive Form & Complex Validation

Reactive HTML binding layout, followed by FormBuilder control setup.

<!-- HTML Template Usage -->
<form [formGroup]="profileForm" (ngSubmit)="submitReactiveForm()">
  <input formControlName="username" />
  <div formGroupName="address">
    <input formControlName="city" />
  </div>
</form>

<!-- TypeScript Component Controller -->
this.profileForm = this.fb.group({
  username: ['', {
    validators: [Validators.required, Validators.minLength(4)],
    asyncValidators: [this.usernameAvailabilityValidator.bind(this)],
    updateOn: 'blur'
  }],
  email: ['', [Validators.required, Validators.email]],
  password: ['', [Validators.required, Validators.minLength(6), this.passwordComplexityValidator]],
  confirmPassword: ['', [Validators.required]],
  address: this.fb.group({
    street: ['', Validators.required],
    city: ['', Validators.required],
    zipCode: ['', [Validators.required, Validators.pattern('^[0-9]{5}$')]]
  }),
  skills: this.fb.array([this.fb.control('', Validators.required)])
}, {
  validators: [this.passwordsMatchValidator]
});

2. Dynamic Form Generation from Schemas

Resolving schema keys in HTML, followed by the dynamic FormGroup builder.

<!-- HTML Template Usage -->
<form [formGroup]="dynamicForm">
  <div *ngFor="let field of dynamicFields">
    <label>{{ field.label }}</label>
    <input [formControlName]="field.key" />
  </div>
</form>

<!-- TypeScript Component Build -->
private initDynamicForm(): void {
  const group: any = {};
  this.dynamicFields.forEach((field) => {
    group[field.key] = this.fb.control(
      field.value || '',
      field.required ? Validators.required : null
    );
  });
  this.dynamicForm = new FormGroup(group);
}

3. Template-Driven Form Declarations

Binding component models and referencing DOM controls locally.

<!-- HTML Template Usage -->
<form #feedbackForm="ngForm" (ngSubmit)="submitTemplateForm(feedbackForm)">
  <input name="email" [(ngModel)]="feedbackModel.email" required email #email="ngModel" />
  <span *ngIf="email.invalid && email.touched">Email is required</span>
</form>

<!-- TypeScript Component Model -->
public feedbackModel = {
  fullName: '',
  email: '',
  category: 'bug',
  message: '',
  subscribe: false
};

4. Dynamic FormArrays (Skills list)

Iterating dynamic arrays in templates, followed by pushing controls in TS.

<!-- HTML Template Usage -->
<div [formGroup]="profileForm">
  <div formArrayName="skills">
    <div *ngFor="let skill of skillsArray.controls; let idx = index">
      <input [formControlName]="idx" />
      <button (click)="removeSkillInput(idx)">Delete</button>
    </div>
  </div>
</div>

<!-- TypeScript Component Controller -->
public get skillsArray(): FormArray {
  return this.profileForm.get('skills') as FormArray;
}

public addSkillInput(): void {
  this.skillsArray.push(this.fb.control('', Validators.required));
}

public removeSkillInput(index: number): void {
  if (this.skillsArray.length > 1) {
    this.skillsArray.removeAt(index);
  }
}
