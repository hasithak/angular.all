Multi-Slot Content Projection

Learn how to build highly reusable wrapper widgets using ng-content selectors to project custom HTML templates into specific slots of a child layout.

Interactive Sandbox

How to test this demo:
  1. Observe how the card below integrates a custom header settings button, a main description text, and bottom primary action buttons.
  2. Click the settings gear icon in the header, or the "CANCEL" / "CONFIRM" footer buttons. These events are declared inside the parent component template, but rendered and projected cleanly inside the child card container.

Code Sample & Concept Explanation

Target Selection Rules:
  • Select Attribute: The selector is specified inside <ng-content select="[attribute-name]">. Any elements bearing that attribute will match and populate the slot.
  • Default Fallback Slot: An <ng-content> tag without a select attribute acts as the default slot. Any elements not matching other slots accumulate there.

1. Parent HTML Layout

<app-shared-card title="Projected Card Demo" subtitle="Inspected via ContentChild">
  <!-- Projects into card-header-actions slot -->
  <div card-header-actions>
    <button mat-icon-button color="primary" (click)="handleChildAlert('Header settings button clicked!')">
      <mat-icon>settings</mat-icon>
    </button>
  </div>

  <!-- Projects into default (body) slot -->
  <p>
    This entire paragraph is defined in the parent component template, but is projected and rendered inside the body of the child component card!
  </p>
  <div class="projected-highlight">
    Custom layout elements inside cards are fully modular.
  </div>

  <!-- Projects into card-footer-buttons slot -->
  <div card-footer-buttons>
    <button mat-button color="warn" (click)="handleChildAlert('Cancel pressed on projected card')">CANCEL</button>
    <button mat-flat-button color="primary" (click)="handleChildAlert('Submit pressed on projected card')">CONFIRM</button>
  </div>
</app-shared-card>

2. Child Card Layout HTML

<div class="card-header">
  <h2>{{ title }}</h2>
  <!-- Selector-based projection slot -->
  <ng-content select="[card-header-actions]"></ng-content>
</div>

<div class="card-body">
  <!-- Default catch-all projection slot -->
  <ng-content></ng-content>
</div>

<div class="card-actions">
  <!-- Selector-based projection slot -->
  <ng-content select="[card-footer-buttons]"></ng-content>
</div>

3. Child Component TS

import { Component, Input, ContentChild, TemplateRef } from '@angular/core';

@Component({
  selector: 'app-shared-card',
  standalone: true
})
export class SharedCardComponent {
  @Input() title = 'Card Title';
  @Input() subtitle?: string;

  // Querying projected template references via Template ID
  @ContentChild('customHeader') customHeaderTemplate?: TemplateRef<any>;
  @ContentChild('customFooter') customFooterTemplate?: TemplateRef<any>;
}
