Code Sample & Concept Explanation

Template Tricks:
  • Zero JS Overhead: Declaring #templateInput on an element makes it accessible globally across the template without writing TypeScript code.
  • Outlet Reusability: Use ngTemplateOutlet to render clean sub-templates without wrapping them inside complex custom components.
  • Null Safety: Standard navigation checks prevent javascript runtime errors when loading remote asynchronous resources.

1. Template Outlet Context Binding

Injecting dynamic layout references and templates.

<!-- Define Templates -->
<ng-template #cardLayout let-hdr let-desc="description">
  <div class="card">
    <h3>{{ hdr }}</h3>
    <p>{{ desc }}</p>
  </div>
</ng-template>

<!-- Load Template dynamically passing context properties -->
<ng-container [ngTemplateOutlet]="cardLayout" 
              [ngTemplateOutletContext]="templateContext">
</ng-container>

<!-- TS -->
public templateContext = {
  $implicit: 'Header Title',
  description: 'Context Description text...'
};

2. Null Safety & Alias Checks

Preventing property errors and binding conditional aliases.

@if (activeUser(); as user) {
