Querying Multiple Instances (@ViewChildren)

Learn how to query, track, and manipulate multiple instances of child components rendered dynamically in the DOM using a reactive QueryList.

Code Sample & Concept Explanation

Understanding QueryList:
  • Reactive Container: QueryList is a reactive array-like wrapper. Every time components are added or removed from the DOM via loops (e.g. *ngFor), the list updates automatically.
  • Dynamic Subscription: You can subscribe to changes in the list using this.childList.changes.subscribe(...).

1. Parent HTML Template

<!-- Node controls to add and remove children -->
<button (click)="addChildNode()">Add Child</button>
<button (click)="removeChildNode()">Remove Child</button>

<!-- Renders child components dynamically based on signal count -->
<div *ngFor="let item of [].constructor(childTriggerCount()); let idx = index">
  <app-fundamentals-child
    [parentMessage]="'Broadcasting state to child ' + (idx + 1)"
    (alertTriggered)="handleChildAlert($event, idx + 1)"
  ></app-fundamentals-child>
</div>

2. Parent Component TS

import { QueryList, ViewChildren, signal } from '@angular/core';

// Track number of children dynamically
public childTriggerCount = signal(2);

// Querying all instances matching the component class
@ViewChildren(FundamentalsChildComponent) 
public childList!: QueryList<FundamentalsChildComponent>;

public addChildNode(): void {
  if (this.childTriggerCount() < 4) {
    this.childTriggerCount.update(c => c + 1);
  }
}

public removeChildNode(): void {
  if (this.childTriggerCount() > 1) {
    this.childTriggerCount.update(c => c - 1);
  }
}

// Handle child alert trigger
public handleChildAlert(msg: string, idx: number): void {
  console.log(`Alert from child ${idx}: ${msg}`);
}

// Mass mutation using foreach iteration
public resetAllChildren(): void {
  this.childList.forEach((child, index) => {
    child.resetChildState();
  });
}

4. Child Component TS

export class ChildComponent {
  // Receiving data
  @Input() parentMessage = '';

  // Defining custom event emitters
  @Output() counterChange = new EventEmitter<number>();

  public incrementCounter(): void {
    this.counter.update(c => c + 1);
    this.counterChange.emit(this.counter());
  }
}
