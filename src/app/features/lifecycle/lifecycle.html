Code Sample & Concept Explanation

Angular Lifecycle Sequence:
  1. ngOnChanges: Fired before ngOnInit and every time an input property changes. Receives a SimpleChanges object containing current and previous values.
  2. ngOnInit: Fired once when component inputs are initialized. Used for setup code.
  3. ngDoCheck: Fired during every change detection cycle, allowing manual tracking of mutations.
  4. ngAfterContentInit / Checked: Fired after content projection elements are bound/checked.
  5. ngAfterViewInit / Checked: Fired after the component's view templates are fully rendered and bindings completed. Perfect for direct DOM work.
  6. ngOnDestroy: Fired right before the component is purged from the DOM. Essential for cleaning up subscriptions and timers.

1. Parent HTML Template

Mounting and binding inputs dynamically to the child component.

<!-- Conditional mount with active property inputs -->
<app-lifecycle-child
  *ngIf="isChildMounted()"
  [textInput]="textValue()"
  [numericInput]="numericValue()"
  (hookFired)="handleHookFired($event)"
></app-lifecycle-child>

2. Child Component TS (Initialization & Outputs)

Tracking input modifications and initialization hooks.

import { Component, Input, Output, EventEmitter, OnChanges, OnInit, SimpleChanges } from '@angular/core';

@Component({
  selector: 'app-lifecycle-child',
  standalone: true,
  template: `<div>Active Child View</div>`
})
export class LifecycleChildComponent implements OnChanges, OnInit {
  @Input() textInput = '';
  @Input() numericInput = 0;
  @Output() hookFired = new EventEmitter<{ hook: string; details?: string }>();

  ngOnChanges(changes: SimpleChanges): void {
    const summary: string[] = [];
    for (const key in changes) {
      const prop = changes[key];
      summary.push(`${key}: '${prop.previousValue}' -> '${prop.currentValue}'`);
    }
    this.hookFired.emit({ hook: 'ngOnChanges', details: summary.join(', ') });
  }

  ngOnInit(): void {
    this.hookFired.emit({ hook: 'ngOnInit', details: 'Initialized component logic.' });
  }
}

3. Child Component TS (View checking & Teardown)

Intercepting template checking cycles and cleaning up references.

import { DoCheck, AfterContentInit, AfterViewInit, OnDestroy } from '@angular/core';

export class LifecycleChildComponent implements DoCheck, AfterContentInit, AfterViewInit, OnDestroy {
  
  ngDoCheck(): void {
    this.hookFired.emit({ hook: 'ngDoCheck', details: 'Checked for changes.' });
  }

  ngAfterContentInit(): void {
    this.hookFired.emit({ hook: 'ngAfterContentInit', details: 'Projected content fully bound.' });
  }

  ngAfterViewInit(): void {
    this.hookFired.emit({ hook: 'ngAfterViewInit', details: 'HTML view fully initialized.' });
  }

  ngOnDestroy(): void {
    this.hookFired.emit({ hook: 'ngOnDestroy', details: 'Component unmounted.' });
  }
}
