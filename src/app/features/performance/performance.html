Code Sample & Concept Explanation

Angular Performance Pillars:
  • Virtual Scrolling: Crucial for large arrays (thousands of elements). Instead of overloading the browser by instantiating thousands of DOM nodes, CDK Virtual Scroll retains a fixed pool of nodes and dynamically swaps element bindings on scroll.
  • TrackBy Function: Tells Angular how to unique-identify array objects. Without it, refreshing an array causes the entire DOM list to be destroyed and recreated. With it, Angular updates only modified DOM rows, eliminating DOM churn.
  • Pure Pipes: Transform inputs to outputs inside templates. Angular caches pure pipe execution results. In contrast, calling component methods directly inside templates (e.g. {{ compute(val) }}) forces re-execution on every single change detection cycle.

1. CDK Virtual Scrolling Implementation

Using Angular CDK to render massive arrays smoothly.

<!-- HTML Template Usage -->
<cdk-virtual-scroll-viewport itemSize="46" class="virtual-viewport">
  <div *cdkVirtualFor="let item of largeItemsList(); let idx = index" class="viewport-item-row">
    <span>Row #{{ idx }}</span>
    <span>{{ item.label }}</span>
  </div>
</cdk-virtual-scroll-viewport>

<!-- TypeScript Component Controller -->
import { ScrollingModule } from '@angular/cdk/scrolling';

public readonly largeItemsList = signal<Array<{ id: number; label: string; value: number }>>([]);

ngOnInit(): void {
  const items = Array.from({ length: 10000 }).map((_, i) => ({
    id: i,
    label: `Performance Metric #{i}`,
    value: Math.floor(Math.random() * 1000) + 1
  }));
  this.largeItemsList.set(items);
}

3. Pure Pipe Memoization Caching

Applying pure pipe filters in templates, followed by the PipeTransform implementation.

<!-- HTML Template Usage -->
<div *ngFor="let num of memoizationNumbers()">
  <code>{{ num | appPureCompute }}</code>
</div>

<!-- TypeScript Pipe Implementation -->
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
  name: 'appPureCompute',
  standalone: true,
  pure: true
})
export class PureComputePipe implements PipeTransform {
  public transform(value: number): string {
    const isPrimeResult = this.isPrime(value);
    return `Prime: ${isPrimeResult ? 'YES' : 'NO'}`;
  }

  private isPrime(num: number): boolean {
    if (num <= 1) return false;
    for (let i = 2; i <= Math.sqrt(num); i++) {
      if (num % i === 0) return false;
    }
    return true;
  }
}

4. Anti-Pattern: Template Method Call

Why you should avoid calling component methods directly inside templates.

<!-- HTML Template Usage (ANTI-PATTERN) -->
<div *ngFor="let num of memoizationNumbers()">
  <code>{{ heavyTemplateMethodCompute(num) }}</code>
</div>

<!-- Inside Component Controller -->
public heavyTemplateMethodCompute(value: number): string {
  Promise.resolve().then(() => {
    this.templateMethodCallCount.update((c) => c + 1);
  });
  const result = this.isPrimeCheck(value);
  return `Prime: ${result ? 'YES' : 'NO'}`;
}
