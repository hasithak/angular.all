Code Sample & Concept Explanation

Angular Router Architecture:
  • Functional Route Guards: Lightweight functions (CanActivateFn, CanDeactivateFn, CanMatchFn) that control route entry, exit, and pattern matching without requiring injectable classes.
  • Functional Resolvers: Fetch backend data *before* the component initializes. The router holds navigation transition until resolving, ensuring seamless transitions without layout shifting.
  • Component Input Bindings: Enabled via withComponentInputBinding(), mapping route path parameter keys (:id) and query parameters directly to component @Input bindings or signals.
  • Child Routes & Lazy Loading: Organize complex feature hierarchies and code-split module bundles effectively.

1. Functional Route Guards (CanActivate, CanDeactivate, CanMatch)

Functional guards execute before navigation transitions complete:

// 1. CanActivateFn: Feature Flag / Condition Guard
export const featureFlagGuard: CanActivateFn = (route, state) => {
  const flagsService = inject(FeatureFlagsService);
  const requiredFlag = route.data['featureFlag'];

  return flagsService.isEnabled(requiredFlag) 
    ? true 
    : inject(Router).createUrlTree(['/dashboard']);
};

// 2. CanDeactivateFn: Prevent Leaving Dirty Forms
export interface HasUnsavedChanges {
  hasUnsavedChanges(): boolean;
}

export const unsavedChangesGuard: CanDeactivateFn<HasUnsavedChanges> = (component) => {
  if (component.hasUnsavedChanges()) {
    return confirm('You have unsaved changes. Discard and leave?');
  }
  return true;
};

// 3. CanMatchFn: Dynamic Route Matching (e.g. A/B Testing / V2 rollout)
export const betaRouteMatchGuard: CanMatchFn = (route, segments) => {
  return inject(ConfigService).isBetaEnabled();
};

2. Router Config & Resolvers

Attaching guards, resolvers, and child hierarchies inside app.routes.ts:

// Functional Resolver definition
export const demoResolver: ResolveFn<any> = (route, state) => {
  return inject(DataService).fetchDetail(route.params['id']);
};

// Routes definition
export const routes: Routes = [
  {
    path: 'routing-demo',
    canMatch: [betaRouteMatchGuard],
    children: [
      {
        path: '',
        component: RoutingDemoComponent,
        resolve: { resolverData: demoResolver }
      },
      {
        path: 'edit/:id',
        component: EditFormComponent,
        canActivate: [featureFlagGuard],
        canDeactivate: [unsavedChangesGuard],
        data: { featureFlag: 'editingStudio' }
      }
    ]
  }
];

3. Router Templates & Programmatic Navigation

HTML navigation bindings, followed by programmatic TS router methods.

<!-- HTML Template Navigation Usage -->
<a [routerLink]="['detail', item.id]" [queryParams]="{ category: item.category, source: 'link' }">

<!-- TypeScript Programmatic Navigation -->
public navigateProgrammatically(id: string, cat: string): void {
  this.router.navigate(['/routing-demo', 'detail', id], {
    queryParams: { category: cat, refreshed: 'true' }
  });
}
