Code Sample & Concept Explanation

RxJS Reactive Extensions:
  • Flattening Maps: Resolve nested observables. Use switchMap to discard old requests, mergeMap for parallel executions, concatMap for queues, and exhaustMap to lock out new inputs.
  • Subjects: Standard Subject passes events only to active subscribers. BehaviorSubject caches the latest value for new subscribers, and ReplaySubject stores a buffer history.
  • Debouncing: Delays event propagation until input stops changing, reducing backend load during keystrokes.

public standardSubject = new Subject<string>();

// 2. Behavior: returns current state (requires default)
public behaviorSubject = new BehaviorSubject<string>('Initial Value');

// 3. Replay: buffers last N items (e.g. 3)
public replaySubject = new ReplaySubject<string>(3);

// Emitting data to all subjects
this.standardSubject.next(val);
this.behaviorSubject.next(val);
this.replaySubject.next(val);

3. Debounce & Distinct Input Filtering

HTML search input element, followed by TS debouncing query stream setup.

<!-- HTML Template Usage -->
<input (input)="handleDebounceInputChange($event)" placeholder="Search..." />
<span>Result: {{ debouncedOutput() }}</span>

<!-- TypeScript Component Controller -->
public readonly debounceInput$ = new Subject<string>();
public debouncedOutput = signal('');

this.debounceInput$.pipe(
  // Wait for 400ms of typing silence
  debounceTime(400),
  
  // Only propagate if search query changed
  distinctUntilChanged()
).subscribe(val => this.debouncedOutput.set(val));

public handleDebounceInputChange(event: Event): void {
  const value = (event.target as HTMLInputElement).value;
  this.debounceInput$.next(value);
}
