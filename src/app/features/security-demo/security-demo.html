Sanitization Reference

Context-specific sanitization:
  • HTML: Used for rich text and innerHTML injection. Strips unsafe scripts, elements.
  • Style: Sanitizes CSS rules bound to attributes.
  • URL: Sanitizes simple page redirects and anchor link tags.
  • Resource URL: Sanitizes scripts, service workers, or iframes loaded from external hosts.

Standard innerHTML Binding

Standard Angular auto-stripping mechanism.

<!-- Angular automatically removes unsafe <script> elements -->
<div [innerHTML]="rawInputString"></div>

Bypassing HTML Security

Marking HTML strings as completely trusted.

import { Component, inject } from '@angular/core';
import { DomSanitizer, SafeHtml } from '@angular/platform-browser';

@Component({
  selector: 'app-security-demo',
  template: `<div [innerHTML]="trustedHtml"></div>`
})
export class SecurityDemoComponent {
  private readonly sanitizer = inject(DomSanitizer);
  public trustedHtml!: SafeHtml;

  public setContent(rawHtml: string) {
    // Bypasses sanitization pipeline completely
    this.trustedHtml = this.sanitizer.bypassSecurityTrustHtml(rawHtml);
  }
}

Allowing frames, dynamic scripts, or external links to execute.
