Code Sample & Concept Explanation

Signal Architecture:
  • signal(initialValue): Declares a read-write signal. Update using .set(val) to overwrite or .update(fn) to calculate values relative to current state.
  • computed(fn): Compiles a read-only derived signal. It automatically tracks any signal read inside fn and caches output dynamically. Only re-evaluates if dependencies change.
  • effect(fn): Spawns side effects. Angular registers dependency signals and runs fn asynchronously whenever their states change. MUST be executed inside an injection context (e.g. constructor).

1. Writable Signals & Mutations

Reading signals in templates, followed by TS declarations and updates.

<!-- HTML Template Usage -->
<span>Quantity: {{ quantity() }}</span>
<button (click)="decrementQuantity()">Decrement</button>
<button (click)="incrementQuantity()">Increment</button>

<!-- Array state mutations -->
<input [(ngModel)]="newTagText" />
<button (click)="addTagItem()">ADD</button>
<span *ngFor="let tag of tags()">{{ tag }}</span>

<!-- TypeScript Component Controller -->
public quantity = signal(1);
public tags = signal<string[]>(['Angular', 'Signals', 'Reactivity']);
public newTagText = '';

public incrementQuantity(): void {
  this.quantity.update((q) => q + 1);
}

public decrementQuantity(): void {
  if (this.quantity() > 1) {
    this.quantity.update((q) => q - 1);
  }
}

public addTagItem(): void {
  if (!this.newTagText.trim()) return;
  this.tags.update((current) => [...current, this.newTagText.trim()]);
  this.newTagText = '';
}

2. Computed Derived Values

Consuming computed values in templates, followed by the computed() function in TS.

<!-- HTML Template Usage -->
<strong>${{ totalCost() }}</strong>
<div *ngIf="isDiscountEligible()">Discount Eligible!</div>

<!-- TypeScript Component Controller -->
public quantity = signal(1);
public unitPrice = signal(25);

public totalCost = computed(() => this.quantity() * this.unitPrice());
public isDiscountEligible = computed(() => this.totalCost() >= 100);

3. Reactive Side Effects

Side effects are strictly TypeScript background routines with auto-tracking.

// Triggered automatically on dependency changes
public readonly effectLogs = signal<SignalEffectLog[]>([]);

constructor() {
  effect(() => {
    const currentTotal = this.totalCost();
    const currentQty = this.quantity();
    const currentPrice = this.unitPrice();
    console.log(`Qty(${currentQty}) * Price($${currentPrice}) = ${currentTotal}`);
  });
}

4. RxJS Interoperability

Consuming interoperable streams in templates, followed by interop helper declarations in TS.

<!-- HTML Template Usage -->
<div *ngFor="let item of productsSignal()">{{ item.name }}</div>

<!-- TypeScript Component Declarations -->
import { toSignal, toObservable } from '@angular/core/rxjs-interop';

// 1. Observable -> Signal
public productsSignal = toSignal(this.products$, { initialValue: [] });

// 2. Signal -> Observable
public quantity$ = toObservable(this.quantity);
