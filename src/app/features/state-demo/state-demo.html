Code Sample & Concept Explanation

State Store Patterns:
  • Single Source of Truth: Wrapping state mutations inside a single store class built on a BehaviorSubject ensures reliable unidirectional flows.
  • Immutability: Always spread previous properties (e.g. { ...state, property: newValue }) rather than editing fields directly, preventing accidental side-effects and enabling history auditing.
  • Time Travel: Keeping histories in undo/redo arrays allows components to jump to previous snapshots instantly.

1. Immutable State Store (BehaviorSubject)

<!-- TypeScript Store Implementation -->
class SimpleStore {
  private readonly stateSubject = new BehaviorSubject<AppState>(initialAppState);
  public readonly state$ = this.stateSubject.asObservable();

  public select<K>(mapFn: (state: AppState) => K): Observable<K> {
    return this.state$.pipe(map(mapFn));
  }

  public setState(reducer: (state: AppState) => AppState): void {
    const currentState = this.stateSubject.getValue();
    const nextState = reducer(currentState);

    this.undoStack.push(currentState);
    this.redoStack = []; // Clear redo list
    this.stateSubject.next(nextState);
  }
}

2. Undo/Redo Stacks & Time Travel

<!-- TypeScript Stack Operations -->
private undoStack: AppState[] = [];
private redoStack: AppState[] = [];

public undo(): boolean {
  if (this.undoStack.length === 0) return false;

  const previousState = this.undoStack.pop()!;
  const currentState = this.stateSubject.getValue();
  this.redoStack.push(currentState);
  
  this.stateSubject.next(previousState);
  return true;
}

public redo(): boolean {
  if (this.redoStack.length === 0) return false;

  const nextState = this.redoStack.pop()!;
  const currentState = this.stateSubject.getValue();
  this.undoStack.push(currentState);

  this.stateSubject.next(nextState);
  return true;
}
